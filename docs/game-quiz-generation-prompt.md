# Инструкция для генерации викторины в JSON

Скопируйте текст ниже в чат с нейросетью, добавьте тему и количество вопросов, а ответ вставьте в админке:
`/admin/quizzes` → «Новая викторина» → «Импорт и экспорт в JSON» → «Заменить вопросы» → «Сохранить».
Рабочий образец лежит рядом: `docs/game-quiz-example.json`.

---

Сгенерируй викторину для игры с друзьями в виде **одного JSON-объекта**, без пояснений до и после, без markdown-обёртки. Тема: `<ТЕМА>`. Вопросов: `<N>`. Язык: русский.

## Структура

```
{
  "title": "...",            // обязательно, до 120 символов
  "description": "...",      // необязательно, до 300 символов
  "timeLimit": 20,           // секунд на вопрос, целое от 5 до 120
  "published": false,        // всегда false: опубликую сам
  "questions": [ ... ]       // от 1 до 50 вопросов
}
```

## Три типа вопросов

**1. Один верный** (`"type": "choice"` или без `type`)

```
{ "text": "...", "options": ["...", "...", "..."], "correct": 1 }
```

- `options`: от 2 до 6 вариантов, каждый до 150 символов, без пустых и без повторов (регистр не различается).
- `correct`: ОДНО значение — номер верного варианта, считая с нуля (`1` = второй вариант), либо точный текст верного варианта.

**2. Несколько верных** (`"type": "multi"`)

```
{ "type": "multi", "text": "...", "options": ["...", "...", "...", "..."], "correct": [0, 2] }
```

- `options` — как выше.
- `correct`: непустой СПИСОК номеров (с нуля) или точных текстов верных вариантов, без повторов.
- Очки: (верно отмеченные − неверно отмеченные) ÷ число верных, не ниже нуля. Пример: из двух верных отмечен один без лишних — половина очков; один верный и один лишний — ноль.

**3. Ввод ответа** (`"type": "text"`)

```
{ "type": "text", "text": "...", "answers": ["Париж", "Paris"] }
```

- `answers`: от 1 до 10 засчитываемых написаний, каждое до 100 символов, с буквой или цифрой. Вместо списка можно один `"answer": "..."`.
- Регистр, «ё/е», запятые, скобки и пробелы по краям не важны. Одна опечатка прощается только в словах от 6 символов без цифр. Поэтому для чисел и коротких слов перечисляй все варианты записи: `["10", "десять"]`.

## Необязательные поля (для любого типа)

- `"image"`: ссылка на картинку. Только `https://...` или путь от корня сайта вида `/папка/файл.webp`. Не `http://`, не `//...`, не `data:`. Без пробелов, до 500 символов. Не выдумывай ссылки: если не уверен, что картинка существует, не добавляй поле.
- `"explanation"`: пояснение, которое показывается всем после закрытия вопроса. Обычный текст, до 600 символов. Чем оно длиннее, тем дольше показывается ответ, так что делай его кратким (1–2 предложения).

## Требования к содержанию

- Один однозначно верный ответ в вопросах типа `choice`; для `multi` верных от 1 до числа вариантов минус один.
- Верные варианты не должны всегда стоять на одном месте: перемешивай позиции.
- Не используй число как `correct` в `choice`, если в `options` есть вариант с таким же текстом (например, варианты `"1","2","3"` и `correct: 2`) — такой ответ неоднозначен и будет отвергнут. В этом случае пиши `correct` текстом: `"2"`.
- Текст вопроса до 300 символов, без нумерации («1.», «Вопрос 1») и без разметки.
- Не добавляй полей, которых нет в описании.
- Проверь, что JSON валиден: двойные кавычки, без комментариев и висячих запятых.

## Что произойдёт при ошибке

Админка покажет первую найденную ошибку с номером вопроса, например:
«Вопрос 3: не отмечено ни одного верного варианта». Исправь и импортируй заново.
