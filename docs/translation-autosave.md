# Автосохранение переводов

Перед запуском обновлённого приложения применить миграцию
`drizzle/0025_translation_save_versions.sql` после `0024_translation_docs.sql`
штатным процессом миграций (`npm run db:migrate`). Существующие тексты сохраняются,
начальная версия каждого поля равна нулю. Миграция проверена на локальном PGlite;
рабочая база при разработке не изменялась.

Каждая правка содержит `expectedVersion` и постоянный `operationId`. Сервер под
блокировкой документа проверяет версию поля, записывает текст, новую версию,
квитанцию операции и журнал в одной транзакции. Версии перевода и комментария
независимы. Повтор принятой операции ничего не записывает. Если после неё поле
изменили, ответ содержит конфликт с актуальным текстом.

В пачке могут быть сохранённые поля и конфликты. HTTP 409 возвращает результаты
всех полей; клиент удаляет только подтверждённые черновики. При конфликте оба
варианта остаются видны до выбора пользователя. Выбор своего черновика создаёт
новую операцию с показанной серверной версией; следующая чужая правка снова
вызовет конфликт.

Клиент отправляет только один запрос за раз, в том числе при скрытии и закрытии
вкладки. Размер JSON ограничен 48 000 байтами и десятью правками. Тайм-аут
20 секунд охватывает получение ответа и чтение JSON. Сетевые ошибки повторяются
с теми же идентификаторами с увеличением задержки до минуты и небольшим разбросом.
HTTP 413 делит пачку; одиночная отклонённая правка и HTTP 400 остаются в браузере
без автоматических повторов до исправления текста. HTTP 404 сохраняет черновики
и останавливает повторы по недействующей ссылке.

Резервные копии хранятся отдельными операциями в localStorage, включая текст,
версию и зависимость от предыдущей неподтверждённой операции. Старые черновики
без версии открываются как конфликт, их автоматическая отправка запрещена.
Открытые до обновления вкладки нужно перезагрузить: старый протокол получает
HTTP 400, после перезагрузки старые черновики можно выбрать явно.

Проверки: `src/lib/client/translation-saver.test.ts`,
`src/lib/data/translation.test.ts`, `src/lib/server/translations.server.test.ts`.
Серверные тесты применяют обе миграции к изолированной базе PGlite.
