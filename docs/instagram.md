# Instagram-автоответы

Автоматизация по ключевым словам через официальный **Instagram API with Instagram Login**
(Facebook-страница не нужна, достаточно профессионального аккаунта):

- публичный ответ на комментарий под постом/рилсом;
- сообщение в директ автору комментария (private reply);
- ответ на входящее сообщение в директе.

Правила настраиваются в админке: `/admin/bot/instagram`. На один комментарий/сообщение
срабатывает **первое** подходящее правило (по возрастанию id). Свои комментарии и
исходящие сообщения (echo) игнорируются, повторные доставки вебхука — тоже
(таблица `instagram_processed`).

## Лимиты Meta

- Private reply на комментарий: **одно сообщение на комментарий**, в течение 7 дней,
  до 750/час на аккаунт.
- Ответ в директе: в течение 24 часов после входящего сообщения (для автоответа на
  входящее — всегда ок).

## Настройка (один раз)

1. **Аккаунт**: Instagram переводится в профессиональный (Business или Creator).
2. **Приложение Meta**: [developers.facebook.com](https://developers.facebook.com) →
   Create App → тип «Business» → добавить продукт **Instagram** → «API setup with
   Instagram login».
3. **Токен**: в разделе Instagram → API setup сгенерировать долгоживущий access token
   для своего аккаунта (кнопка Generate token после привязки аккаунта). Токен живёт
   около 60 дней. Сайт автоматически вызывает `GET /refresh_access_token` при первом
   запуске, затем примерно раз в 30 дней. Это запас до истечения срока, а не лимит Meta.
   Продлевать можно только действующий токен старше 24 часов. При ошибке (в том числе
   для только что созданного токена) сайт сохраняет прежнее значение и повторяет через сутки.
4. **Разрешения**: `instagram_business_basic`, `instagram_business_manage_messages`,
   `instagram_business_manage_comments`. Пока приложение в **Development mode** и
   аккаунт добавлен в тестеры/роли приложения — App Review не нужен.
5. **Вебхук**: в приложении → Webhooks → Instagram:
   - Callback URL: `https://kalmykov-psy.ru/api/instagram/webhook`
   - Verify token: значение `INSTAGRAM_VERIFY_TOKEN` из `.env`
   - Подписаться на поля **`comments`** и **`messages`**.
6. **Env** (`.env` на проде, затем перезапуск):

   ```
   INSTAGRAM_ACCESS_TOKEN=<долгоживущий токен из шага 3>
   INSTAGRAM_VERIFY_TOKEN=<случайная строка, та же что в шаге 5>
   INSTAGRAM_APP_SECRET=<App Secret из Settings → Basic>
   INSTAGRAM_PROXY=socks5://127.0.0.1:1080
   # Необязательно: абсолютный путь к постоянному приватному файлу токена
   INSTAGRAM_TOKEN_FILE=/root/andrei/tmp/instagram-token.json
   ```

   `INSTAGRAM_PROXY` — тот же SOCKS5, что для Telegram Bot API: graph.instagram.com
   с хостинга напрямую недоступен. Без `INSTAGRAM_ACCESS_TOKEN` интеграция полностью
   выключена (вебхук отвечает 200 и ничего не делает).

## Кнопка со ссылкой

В редакторе правила заполните обычный текст сообщения и два поля «Кнопка со ссылкой»:
название (например, «Открыть материал») и полный URL http(s). Кнопка отправляется
как официальный Instagram Button Template (`template_type: button`, `web_url`).
Это одно сообщение, в том числе для private reply на комментарий. До 640 символов
в тексте и до 20 в названии кнопки; при превышении редактор показывает ошибку,
ничего не обрезая. Оба поля пустые — прежнее обычное текстовое сообщение.
Внешний вид задаёт Instagram; предпросмотр в админке ориентировочный.

Официальное описание типов шаблонов: https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api?entity=request-23987686-b217bc6c-d9fb-4d65-bf5e-fcadf650ad5c

## Автопродление и хранение токена

Автопродление запускается в production при старте сайта и проверяет срок каждый час.
После успешного продления возвращённый токен атомарно сохраняется в приватном файле
`tmp/instagram-token.json` (права 0600). Сайт сразу использует его для новых отправок;
перезапуск PM2 не нужен. После падения/перезагрузки значение читается из этого файла.
Даты продления/истечения и ошибка видны в админке, секрет пользователю не передаётся.

Сохраняйте этот файл и каталог `tmp` при обновлении сайта, как и `.env`.
Для отдельных каталогов релизов задайте `INSTAGRAM_TOKEN_FILE` на постоянное место.
Файл исключён из Git и не должен попадать в публичные архивы/статику.
Автопродление не меняет `.env`: его токен служит исходным подключением. Если вручную
заменить `INSTAGRAM_ACCESS_TOKEN` в `.env` и перезапустить PM2, сохранённый токен старого
подключения перестанет использоваться. Перезапускайте приложение с загрузкой env до
старта Node, например для текущего сервера:

```sh
pm2 restart svelte-app2 --node-args="--env-file=/root/andrei/.env" --update-env
pm2 save
```

При отозванном доступе/смене пароля/истёкшем токене потребуется заново подключить
аккаунт и заменить исходный токен. Продление не может восстановить отозванные права.

## Обновление существующего сервера

1. До установки новой сборки примените **только** `drizzle/0023_instagram_link_button.sql`
   к рабочей БД (добавляет два nullable-поля; существующие правила сохраняются).
   При штатном журнале миграций это включено в `npm run db:migrate`; если раньше SQL
   применяли вручную, не переисполняйте все старые миграции.
2. Обновите сборку и обеспечьте запись процессу сайта в каталог `INSTAGRAM_TOKEN_FILE`.
3. Перезапустите `svelte-app2` указанной выше командой и сохраните конфигурацию PM2.
4. Проверьте правило с URL-кнопкой в Instagram на Android/iOS и обычное правило без кнопки.
   В админке должен появиться статус автопродления. Новый токен может получить первую
   успешную попытку только на следующий день.

В этой рабочей копии также есть ранее подготовленная миграция 0022 и другие изменения.
Перед установкой полной сборки учтите `docs/security-deployment.md`; не заменяйте
серверные `.env`, `uploads` или `tmp` содержимым локального проекта.

## Как это работает в коде

- `src/routes/api/instagram/webhook/+server.ts` — GET-верификация подписки и приём
  событий (подпись `X-Hub-Signature-256` проверяется, если задан `INSTAGRAM_APP_SECRET`).
- `src/lib/server/instagram.server.ts` — матчинг правил и вызовы Graph API
  (`/{comment_id}/replies`, `/me/messages`).
- Таблицы: `instagram_rules` (правила, счётчик срабатываний) и `instagram_processed`
  (идемпотентность). Миграция `drizzle/0008_instagram_rules.sql` — применяется
  вручную через psql, как остальные.

## TikTok

Публичного API для ответов на комментарии и директ у TikTok нет (только партнёрская
программа Messaging Partners для платформ уровня Sprinklr). Единственное «лёгкое» —
нативное приветственное сообщение: приложение TikTok → бизнес-аккаунт →
Business Suite → Auto messages.
